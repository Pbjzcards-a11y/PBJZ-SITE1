Nelko printer setup — read this before the first print
Windows → Printers → Nelko → Printing preferences: set the paper size to your actual label stock (1.5 × 1 in / 38 × 25 mm). Do this first — the browser can't override it.

In the print dialog: Nelko as the printer, Margins None, Scale 100% (not "Fit to page" — that shrinks every label), and turn Headers and footers off so the page URL doesn't print on your labels.

Print one label first. If the text sits high, low, or clipped, nudge the Label size boxes above by a millimetre or two rather than changing anything in Windows.
